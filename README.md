# ✊📄✂️ Stone Paper Scissor Game

A simple and interactive Stone Paper Scissor game built using HTML, CSS, and JavaScript. This project allows users to play the classic Stone Paper Scissor game against the computer with instant results.

## 🚀 Features
- User-friendly interface
- Random computer choice generation
- Instant win/lose/draw results
- Responsive design
- Beginner-friendly JavaScript project

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎮 How to Play
1. Open `index.html` in your browser.
2. Choose Stone, Paper, or Scissor.
3. The computer will randomly select its choice.
4. The winner will be displayed instantly.

### Rules
- Stone beats Scissor
- Scissor beats Paper
- Paper beats Stone
